# 10-Minute Demo Setup

1. Push this folder to `samradh4/englishplatform.project`.
2. Wait for Render to show **Live**.
3. Open the site on laptop Wi-Fi and phone mobile data.
4. Register both accounts.
5. Admin approves both with the same level and a 1-day trial.
6. Create and approve a room with limit 5.
7. Join, allow microphones, and check that the voice banner says the secure relay is active.
8. Test raise hand, mute one, mute everyone, chat, and remove user.
9. Keep the admin page open during the client demo.
