# Bolo English V21 — Free AI Voice Partner

Added `/ai-practice`, a zero-paid-API English practice partner that works with browser speech recognition and speech synthesis.

## Included
- Voice input with Chrome/Edge Web Speech support
- Spoken bot replies using system/browser voices
- Speaker on/off
- Voice selector and speed control
- Conversation transcript
- Typed fallback when speech recognition is unavailable
- Daily, interview, beginner, travel, college, and random-topic modes
- Level-aware beginner default
- Gentle corrections for common English mistakes
- Mobile, tablet, laptop, and desktop layouts
- Dashboard promo and direct launch button
- Access limited to active free-trial/paid members (admin also allowed)

## Cost
The default implementation needs no external paid AI API key. It is intentionally designed for a free demo/early launch. For truly generative, open-ended AI later, connect a server-side LLM provider and keep its API key off the browser.
