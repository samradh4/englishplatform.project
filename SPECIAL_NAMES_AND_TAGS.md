# Special names and verified tags

The administrator can now assign a public display name and a verified role tag to registered members and private-link guests.

Examples: Teacher, Senior Teacher, Mentor, Guest Speaker, Counsellor, Trainer, Moderator, VIP Guest.

## Registered members
Open Admin Panel → Member management. Edit **Special display name** and **Special tag**, then choose **Save profile**. The update appears in voice rooms and chat without requiring the member to log out.

## Private-link guests
After a guest joins a private video link, open the link card in Admin Panel → Guest names and phone numbers. Edit the guest's special display name/tag and click **Save name & tag**. The label updates live inside the private video session.

Only the administrator API can assign or remove these tags.
